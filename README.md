# TextConvo &middot; Engineering Standards

This repository holds the **default community health files** and shared engineering templates for every public TextConvo repository.

GitHub applies the files below automatically to any TextConvo repository that does not define its own version.

| File | Applies to | Purpose |
| --- | --- | --- |
| [CONTRIBUTING.md](CONTRIBUTING.md) | All public repos | How to propose changes, branch, commit, and open a pull request. |
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | All public repos | Expected behaviour in issues, pull requests, and discussions. |
| [SECURITY.md](SECURITY.md) | All public repos | Coordinated vulnerability disclosure process. |
| [SUPPORT.md](SUPPORT.md) | All public repos | Where to get help. |
| [CODEOWNERS](CODEOWNERS) | This repo | Default review ownership template. |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | All public repos | Pull request checklist. |
| [.github/ISSUE_TEMPLATE](.github/ISSUE_TEMPLATE) | All public repos | Bug, feature, documentation, and example-request forms. |

## Shared templates

| Template | Use it for |
| --- | --- |
| [templates/README_TEMPLATE.md](templates/README_TEMPLATE.md) | Starting a new public repository with a consistent README. |
| [templates/RELEASE_TEMPLATE.md](templates/RELEASE_TEMPLATE.md) | Writing GitHub release notes. |
| [templates/labels.yml](templates/labels.yml) | The standard label set applied to every public repository. |
| [templates/REPOSITORY_STANDARDS.md](templates/REPOSITORY_STANDARDS.md) | Descriptions, topics, discussion categories, and branch conventions. |

## What lives on GitHub, and what does not

TextConvo product code is private. Public repositories contain examples, specifications, SDK surfaces, and documentation only &mdash; never platform implementation, orchestration logic, infrastructure, or credentials.

Reference documentation is **not** duplicated here. [textconvo.ai/docs](https://textconvo.ai/docs) is the single source of truth; this account is the public engineering landing page.
